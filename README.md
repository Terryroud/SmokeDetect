ИИ-детекция нарушений и мгновенное оповещение для продвижения ЗОЖ и контроля порядка городских пространств ФТ «Сириус».

Данные с камер хранятся в виде json:
```
[
  {"lat": 43.4080, "lng": 39.9490, "intensity": 1.8},
  {"lat": 43.4082, "lng": 39.9493, "intensity": 1.7},
  ...
]
```
, где:

```
"lat" - широта камеры;
"lng" - долгота камеры;
"intensity" - интенсивность, количество курящих.
```
